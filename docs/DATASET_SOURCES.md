## Data interpretation cautions

- Palghar district was formed in 2014. Census 2011 district/sub-district records may refer to the earlier Thane administrative geography; preserve that context when quoting figures.
- Government portals, official publications, secondary directories and academic sources have different authority and update cycles.
- Conflicting figures should be retained with source notes rather than silently reconciled.
- Missing indicators should remain missing/unknown, not be converted to zero.
- For a reproducible training run, create a separate run manifest and identify the exact documents actually used.
